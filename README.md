# API User Information

## 📌 Project Description

This Python project fetches user information from an online REST API using the `requests` library.

The program connects to the **JSONPlaceholder API**, retrieves user data in JSON format, converts it into Python data, and displays important information such as:

* User ID
* Name
* Username
* Email
* City

The project also includes error handling for connection failures, request timeouts, and other request-related errors.

---

## 🚀 Features

* Fetches user data from an online API
* Uses the Python `requests` library
* Converts JSON response into Python data
* Displays user information in a readable format
* Checks HTTP status code
* Handles connection errors
* Handles timeout errors
* Handles other request exceptions
* Uses a 10-second request timeout

## 📦 Installation

First, make sure Python is installed on your computer.

Then install the `requests` library using:

```bash
pip install requests
```

If `pip` does not work, try:

```bash
python -m pip install requests
```

---

## ▶️ How to Run

Open the project folder in VS Code or Command Prompt.

Run the Python file using:

```bash
python api_users.py
```
